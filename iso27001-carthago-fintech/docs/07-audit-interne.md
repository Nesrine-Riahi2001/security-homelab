# 07 — Programme d'audit interne (clause 9.2)

**Statut : modèle à compléter.**

## 1. Programme

| Champ | À renseigner |
|---|---|
| Objectif de l'audit | Vérifier la conformité du SMSI à ISO/IEC 27001:2022 et à ses propres exigences |
| Périmètre | Périmètre du SMSI validé (document 03) |
| Critères d'audit | Clauses 4 à 10, contrôles applicables de la SoA, politiques du SMSI |
| Auditeur(s) | Personne indépendante de l'activité auditée |
| Fréquence | Au moins une fois avant l'audit de certification |
| Méthode | Entretiens, revue documentaire, échantillonnage de preuves |

## 3. Questions types

- Montrez-moi la dernière revue d'accès du système X : qui l'a réalisée, quels écarts, quelles actions ?
- Comment un nouveau fournisseur critique est-il évalué avant signature ?
- Quel est le délai réel de désactivation d'un compte après un départ, sur les trois derniers cas ?

## 4. Modèle de rapport

| N° | Clause ou contrôle | Constat | Preuve | Classification | Action proposée |
|---|---|---|---|---|---|
| 1 | | | | Non-conformité majeure / mineure / observation / point fort | |

Définitions à fixer dans le programme : une non-conformité majeure remet en cause la capacité du SMSI à atteindre ses résultats ; une non-conformité mineure est un écart isolé ; une observation est une piste d'amélioration.
